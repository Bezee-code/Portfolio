🏗️ Platform Model Routing Architecture

1. Multi-Tiered GenAI Translation Pipeline

Instead of routing all text through generic translation APIs or heavy multi-modal LLMs, Firefly Transcreate utilizes a two-tier model gateway. Short-form headlines use a lightweight domain-adapted model trained on regional commercial copy, keeping response latency under 1.8 seconds.

PM Decision Rationale: High-velocity marketing creators abandon tools if localization takes over 3 seconds. Latency budget caps multi-modal generation to complex visual scenes only.

2. Bounding Box & Typography Auto-Scaler

Languages vary drastically in character density. German text expands by up to 35% compared to English, while Japanese requires larger line-height for legibility. The layout engine dynamically adjusts font size, letter spacing, and line height inside SVG vector text frames upon transcreation payload return.

PM Decision Rationale: Prevents design breakage without requiring manual frame resize by non-designer users, directly protecting exported asset quality.

3. Cultural Context & Festival Knowledge Graph

The prompt engine automatically attaches regional metadata based on target geographic selection (e.g. converting generic "Fall Sale" into "Diwali Dhamaka" in India, or "Golden Week Specials" in Japan).

PM Decision Rationale: Transcreation requires cultural intent matching, not literal dictionary replacement. User research proved 82% of global SMBs struggle with local holiday context.

🛡️ Product Guardrails & Edge Case Matrix

1. Brand Name Protection & Trademark Exclusion

Maintains an immutable Brand Term Lock List. Product names, trademarked slogans, and proper nouns are flagged with zero-transcreation tokens to prevent hallucinated translations of core brand entities.

PM Decision Rationale: Enterprise accounts indicated brand safety as their #1 fear when adopting AI content tools.

2. Low-Confidence Fallback & Manual Override

If the transcreation confidence score drops below 0.82 (e.g., highly specialized legal disclaimers or niche technical jargon), the system highlights the text box in amber and provides a 1-click side-by-side edit panel for human approval.

PM Decision Rationale: Eliminates hallucination risk on sensitive copy while preserving speed for 90% of standard marketing text.

3. Bi-Directional Layout Flipping (RTL Support)

Automatically flips design canvas layouts, alignment anchors, and call-to-action button placements when transcreating into Right-to-Left languages like Arabic and Hebrew.

PM Decision Rationale: True internationalization requires structural layout mirroring, not just text string changes.
