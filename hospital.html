2. ServiceNow & Kore.ai Module Specifications

Healthcare CSM ServiceNow

System of record for patient 360 profiles, insurance pre-auth tracking, and clinical case management.

  • Master patient index (MPI) deduplication
  • Pre-auth approval SLA lifecycle tracking

Flow Designer ServiceNow

Low-code process engine executing automated sub-flows between AI agents, nurse approvals, and doctor signatures.

  • Automated decision tables for triage
  • API timeout fallback queue creation

Integration Hub (FHIR) ServiceNow

Pre-built spokes connecting ServiceNow directly to Epic, Cerner, and Payer portals via HL7 FHIR APIs.

  • Query for Patient, Observation & Claim resources
  • SMART-on-FHIR OAuth 2.0 security

Kore.ai XO Platform Kore.ai

Core NLU engine driving multi-turn conversation dialogs, intent classification, and patient sentiment scoring.

  • Multilingual support (English, Hindi, regional)
  • High accuracy intent resolution

SearchAssist (RAG Engine) Kore.ai

Retrieval-Augmented Generation engine over hospital clinical guidelines, drug interaction rules, and SOPs.

  • Vector database RAG search (Pinecone)
  • Zero hallucination clinical guardrails

IRM / GRC Compliance Governance

Ensures 100% HIPAA compliance, immutable audit logging, and role-based access control (RBAC).

  • Full clinical evidence logging
  • Role-based encryption standards
